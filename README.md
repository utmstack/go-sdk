# utmstack/go-sdk

Go SDK for UTMStack SIEM and EventProcessor plugins, rules, and storage abstractions.

## Major Versions

| Branch | Go Module Path | Target Platform | Packages |
| :--- | :--- | :--- | :--- |
| `v1` | `github.com/utmstack/go-sdk` | UTMStack `v11` / EventProcessor `v1` | `plugins` |
| `v2` | `github.com/utmstack/go-sdk/v2` | UTMStack `v12` / EventProcessor `v2` | `plugins`, `store` |

Shared non-SIEM packages (`catcher`, `os`, `utils`) remain in `github.com/threatwinds/go-sdk`.
